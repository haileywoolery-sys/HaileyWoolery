# 🚀 Python Portfolio Suite

A consolidated portfolio showcasing a diverse suite of six native Python applications. This repository demonstrates solid proficiency in **Object-Oriented Programming (OOP)**, **Data Structures & Algorithms**, **File System I/O**, and dynamic memory management.

---

## 🛠️ The Applications

### 1. 📊 Budget Tracker App
- **Description:** An object-oriented ledger utility that manages user accounts, allocates funds across customizable spending categories, and dynamically computes financial balances.
- **Key Features:** Generates a cleanly formatted, terminal-based bar chart displaying spending distributions.

### 2. 🎮 Game Character Stat Tracker
- **Description:** A modular game-state tracker designed to store, manage, and scale attribute sets, inventory allocations, and experience point tracking for role-playing characters.
- **Key Features:** Utilizes local data serialization to persist game progress across application restarts.

### 3. 🔑 Custom Hash Table
- **Description:** An interview-ready data structure built completely from scratch using low-level Python arrays.
- **Key Features:** Implements a custom hashing engine using **chaining** (linked list concepts) for collision resolution to maintain $O(1)$ average-case lookup and insertion speeds.

### 4. 📐 Polygon Area Calculator
- **Description:** A mathematical utility engineered around **class inheritance** to instantiate custom shapes (such as Rectangles and Squares).
- **Key Features:** Dynamically recalculates geometric metrics like total surface area, perimeters, and diagonal constraints based on scalar transformations.

### 5. 🗼 Tower of Hanoi Solver
- **Description:** An algorithmic application that visually mapping out steps to resolve the classic mathematical puzzle.
- **Key Features:** Written via optimized **recursion** to showcase clean memory stack allocation and execution tracing.

### 6. ⚙️ System Configuration Manager
- **Description:** A lightweight, robust system tool built to securely read, parse, and write key-value properties.
- **Key Features:** Safely updates local system variables and checks values against automated validation rules to prevent runtime crashes.
